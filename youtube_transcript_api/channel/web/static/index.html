Cookie export guide

        
      

      

        
When you need cookies

        

          YouTube may block scraping with a bot check or sign-in prompt when it cannot verify a logged-in session.
        

        
Option A: Browser auto-read

        
Select your browser in Advanced. Close the browser completely before starting an export.

        
    
          
  • brave — default Brave profile
    • 
          
  • brave:Default — named profile
    • 
          
  • Full path syntax supported on Windows
    • 
        

        
Option B: Netscape cookie file

        
Recommended for Brave on Windows. Export youtube.com cookies to a .txt file.

        
    
          
  1. Install Get cookies.txt LOCALLY in Brave.
    2. 
          
  2. Sign into YouTube, export cookies for youtube.com.
    3. 
          
  3. Paste the path into Cookie file path; set Cookies browser to None.
    4. 
        

        
Troubleshooting

        
    
          
  • Database locked — quit the browser fully and retry.
    • 
          
  • Empty cookie file — re-export while signed in.
    • 
          
  • Bot check persists — fresh export or different account.
    • 
        

        

          Security: Cookie files grant session access. Treat them like passwords.
